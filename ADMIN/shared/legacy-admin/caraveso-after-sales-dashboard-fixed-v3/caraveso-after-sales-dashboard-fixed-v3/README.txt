CaraVeso - Quản lý dịch vụ hậu mãi

Cấu trúc:
- index.html: giao diện chính
- style.css: toàn bộ CSS, dùng biến màu và bố cục responsive
- script.js: fetch data.json, render bảng, lọc, phân trang, mở chi tiết, duyệt/từ chối yêu cầu
- data.json: dữ liệu hậu mãi mẫu
- assets/: icon, avatar, ảnh minh chứng

Gợi ý chạy:
- Mở bằng VS Code Live Server để fetch data.json hoạt động chuẩn.
- Nếu mở trực tiếp bằng file://, script.js có fallback dữ liệu để vẫn hiển thị demo.
